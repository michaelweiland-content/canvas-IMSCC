Help and limitations
  • One download: everything you pick comes as a single .zip with a folder for each kind of content. If you pick just one item, you get that file directly.
  • Getting the file: in your Canvas course go to Settings → Export Course Content, choose Course, and download the .imscc file when it's ready.
  • Classic question banks are always included in a course export.
  • New Quizzes item banks are only included when a New Quiz in the course uses them. A bank no quiz uses won't be in the file.
  • Random question groups: Canvas picks questions at random when a student takes the quiz. The Word file lists the whole pool and notes how many get picked.
  • Question types: multiple choice, true/false, multiple answers, matching, fill in the blank(s), dropdowns, numerical, formula, essay, file upload and text-only items are supported. Newer New Quizzes types (hot spot, ordering, categorization) are shown as well as possible and flagged for review.
  • Course files (Word, PDF, PowerPoint, images, video) are copied out exactly as they were uploaded. Files linked from Google Drive, OneDrive, YouTube or Canvas Studio aren't stored in the export.
  • Not in any export: student submissions, grades, quiz attempts and discussion replies. Canvas course exports contain course content only.
  • Equations appear as their LaTeX text. Images stored in the course files are embedded; images linked from outside Canvas are shown as a note.
  • Data handling: treat the Word files with the same care as the original exam content.

Works with Canvas course exports (.imscc). Uses JSZip and docx (MIT licensed), bundled with this site.
